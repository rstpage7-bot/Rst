# مشروع جوالة الريادة — نسخة قابلة للربط بقاعدة بيانات

المشروع React + Vite + Supabase، باللغة العربية واتجاه RTL، ويحتوي على:
- موقع تعريفي متجاوب.
- نموذج طلب انضمام يحفظ الطلبات في Supabase بعد الإعداد.
- تسجيل دخول للمسؤول عبر Supabase Auth.
- لوحة إدارة لعرض الطلبات وتغيير حالتها.
- سياسات RLS لمنع الزوار من قراءة الطلبات أو تعديلها.
- شعار وصور مرتبطة بموقع جامعة الريادة الرسمي. تأكد من إذن إعادة الاستخدام قبل العرض الرسمي.

## 1) إنشاء مشروع Supabase
1. افتح https://supabase.com/ وسجّل الدخول.
2. أنشئ مشروعًا جديدًا واحتفظ بكلمة مرور قاعدة البيانات في مكان آمن.
3. افتح SQL Editor ثم New query.
4. انسخ محتوى `supabase/schema.sql` بالكامل والصقه ثم اضغط Run.

## 2) إنشاء حساب مسؤول
1. في Supabase افتح Authentication ثم Users ثم Add user.
2. أنشئ حسابًا ببريد المسؤول وكلمة مرور قوية. لا تضع كلمة المرور في ملفات المشروع.
3. افتح SQL Editor ونفّذ الاستعلام التالي بعد استبدال البريد:
   ```sql
   update public.admin_profiles p
   set is_admin = true
   from auth.users u
   where p.user_id = u.id and u.email = 'YOUR_ADMIN_EMAIL';
   ```
4. لا تفعّل صلاحية مسؤول لحسابات غير موثوقة. لا يوجد تسجيل مسؤول عام في الموقع.

## 3) ربط المشروع بـ Supabase
1. من Supabase افتح Project Settings ثم API (أو Data API حسب الواجهة).
2. انسخ Project URL والمفتاح العام publishable/anon فقط.
3. في مجلد المشروع انسخ `.env.example` إلى ملف جديد اسمه `.env.local`.
4. ضع القيم بهذا الشكل:
   ```
   VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
   VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY
   ```
5. لا تستخدم `service_role` أو أي مفتاح سري في الواجهة أو GitHub.

## 4) النشر على GitHub وVercel
1. ارفع ملفات المشروع ومجلداته إلى جذر مستودع GitHub (لا ترفع `node_modules` ولا `.env.local`).
2. افتح Vercel > Add New > Project واستورد المستودع.
3. Framework: Vite، Build Command: `npm run build`، Output Directory: `dist`.
4. من Project Settings > Environment Variables أضف:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   ثم أعد النشر Redeploy.

## 5) الاختبار قبل التسليم
- أرسل طلبًا تجريبيًا من الموقع.
- سجّل الدخول بحساب المسؤول من رابط "دخول المسؤول" في أسفل الصفحة.
- تأكد أن الطلب ظهر، ثم جرّب تغيير حالته.
- اختبر الموقع من الهاتف.
- راجع سياسة الخصوصية والموافقة على جمع بيانات الطلاب مع إدارة الجامعة قبل فتح النموذج للجمهور.

## تنبيهات مهمة
- هذه نسخة أولية تقنية وليست اعتمادًا رسميًا من الجامعة.
- الصور والشعار مرتبطان بموقع الجامعة الرسمي وقد تتغير روابطهما. يلزم إذن من الجامعة لاستخدامهما في نشر رسمي.
- لا تجمع رقمًا جامعيًا أو هاتفًا أو بريدًا إلا لغرض واضح وبعد موافقة الجهة المسؤولة.
- أضف CAPTCHA أو وسيلة حماية من الرسائل الآلية ومراجعة خصوصية قبل فتح النموذج للعامة.
